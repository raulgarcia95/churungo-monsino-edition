# Street Fighter II: Churungo Monsino Edition

Web estática para GitHub Pages. `index.html` abre la ROM con EmulatorJS y carga las pistas personalizadas MSU desde `churungo-msu-assets.zip`.

Archivos necesarios para publicar:
- `index.html`
- `Street Fighter II - Churungo Monsino edition.sfc`
- `churungo-msu-assets.zip`

Los archivos `.msu` y `.pcm` se mantienen también en esta carpeta como copia de trabajo. La web usa el ZIP para depositarlos juntos en el emulador antes de abrir la ROM.

Para GitHub Pages: publicar la rama principal desde la raíz del repositorio.
